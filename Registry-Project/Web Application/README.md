# Universal Gift Registry — Web Application

A web-based implementation of the Universal Gift Registry developed for **CSCI 3000 – Web Development**.

This project represents a second implementation of the Universal Gift Registry system originally developed as a Java desktop application during a Software Engineering course. Rather than recreating the desktop architecture, this version reimplements the application using modern web technologies while preserving the core functionality.

The complete implementation, source code, and installation instructions are maintained in a dedicated repository.

---

## Project Overview

The application allows users to:

- Register and authenticate accounts
- Create and manage gift registries
- Add and remove registry items
- Search for another user's registry
- View public registry information
- Purchase items from another user's registry
- Access shipping information when permitted by the registry owner

The project demonstrates the transition from a desktop application to a browser-based client while maintaining a common application workflow and database-backed architecture.
