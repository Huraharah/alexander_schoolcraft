# Binary Search Tree

A reference-based Binary Search Tree implementation developed for a Data Structures and Algorithm Analysis course.

The project implements a variety of recursive Binary Search Tree operations, including insertion, searching, traversal, removal, subtree comparison, and Lowest Common Ancestor (LCA) determination.

## Original Assignment

[View the assignment](assignment/Binary_Search_Tree.pdf)

## Project Context

This project was completed for a Data Structures and Algorithm Analysis course.

The assignment focused on implementing a reference-based Binary Search Tree using recursive algorithms for searching, insertion, traversal, and structural analysis.

The `Node` class was supplied as part of the assignment; the Binary Search Tree implementation and testing code were developed for the project.

## Features

- Binary Search Tree implementation
- Recursive insertion
- Recursive search
- Node removal
- In-order traversal
- Tree height and depth calculations
- Minimum and maximum lookup
- Parent lookup
- Subtree comparison
- Branch removal
- Lowest Common Ancestor (LCA)

## Project Structure

src/
├── BinarySearchTree.java
├── Node.java
└── MainClass.java

- `BinarySearchTree.java` implements the tree algorithms.
- `Node.java` defines the binary tree node structure.
- `MainClass.java` exercises each required operation.
