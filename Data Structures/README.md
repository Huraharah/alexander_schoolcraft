# CSCI 3200 – Data Structures and Algorithm Analysis

This directory contains selected coursework completed for **CSCI 3200 – Data Structures and Algorithm Analysis**. The projects focus on implementing fundamental data structures and algorithms from first principles, emphasizing both their underlying representations and the algorithms that operate on them.

Rather than relying on Java's built-in collection framework, these assignments required implementing core data structures directly, providing practical experience with algorithm design, recursion, graph traversal, and asymptotic complexity analysis.

The projects are organized in roughly the order they were completed throughout the semester, reflecting the progression from linear data structures (arrays and linked lists) to hierarchical structures (binary search trees) and finally graph representations and traversal algorithms.

---

## Projects

### Array-Based Restaurant Manager

An object-oriented restaurant management system implemented using fixed-size reference arrays. The project demonstrates array manipulation, searching, insertion, deletion, and basic object-oriented design.

**Concepts**
- Reference arrays
- Object-oriented programming
- Linear search
- Array insertion and deletion

---

### Generic Singly Linked List

A generic singly linked list implementation supporting ordered insertion, searching, removal, merging, and traversal using Java Generics.

**Concepts**
- Linked lists
- Java Generics
- Comparable interface
- Abstract Data Types (ADTs)

---

### Binary Search Tree

A recursive Binary Search Tree implementation supporting insertion, searching, removal, traversal, subtree comparison, and Lowest Common Ancestor (LCA) computation.

**Concepts**
- Binary Search Trees
- Recursion
- Tree traversals
- Divide-and-conquer algorithms

---

### Adjacency Matrix Graph

A graph Abstract Data Type implemented using an adjacency matrix with support for graph property analysis and traversal algorithms.

**Concepts**
- Graph theory
- Adjacency matrices
- Breadth-First Search (BFS)
- Depth-First Search (DFS)
- Graph connectivity
