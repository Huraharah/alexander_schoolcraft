# CSCI 4810 – Digital Signal Processing

This directory contains selected coursework completed for **CSCI 4810 – Digital Signal Processing**. The projects explore the mathematical and computational foundations of modern signal processing, including frequency-domain analysis, digital filtering, image manipulation, and audio processing using MATLAB.

The coursework emphasizes implementing signal-processing algorithms from first principles while developing an understanding of the underlying mathematical concepts behind the Fast Fourier Transform (FFT), convolution, digital filtering, and frequency analysis.

---

## Projects

### Speech Enhancement Using Digital Signal Processing

A semester-long project implementing a complete speech enhancement pipeline for noisy audio recordings.

The implementation combines classical digital signal processing techniques, including Butterworth bandpass filtering and frequency-domain spectral subtraction, to improve speech intelligibility while preserving the underlying voice signal.

**Highlights**

- Speech enhancement pipeline
- Butterworth bandpass filtering
- Fast Fourier Transform (FFT)
- Spectral subtraction
- Inverse FFT reconstruction
- Audio normalization
- Waveform visualization
- Formal technical report

**Technologies**

`MATLAB` `Python` `Digital Signal Processing` `FFT`

---

### DTMF Telephone Keypad Decoder

A MATLAB implementation of a Dual-Tone Multi-Frequency (DTMF) decoder that identifies telephone keypad presses by analyzing their characteristic frequency pairs.

The assignment required decoding keypad tones using FFT analysis and digital filtering without relying on MATLAB peak-detection helper functions.

**Highlights**

- FFT-based frequency analysis
- Digital filtering
- Frequency-domain signal identification
- Telephone keypad decoding

**Technologies**

`MATLAB` `FFT` `Signal Processing`

---

### Image Composition

A MATLAB image-processing assignment demonstrating image manipulation through matrix operations and pixel-level processing.

The project focuses on constructing composite images while reinforcing MATLAB's array-oriented programming model.

**Highlights**

- Image manipulation
- Matrix operations
- Pixel processing
- MATLAB graphics

**Technologies**

`MATLAB` `Image Processing`

## Repository Organization

The repository is organized around representative projects rather than every individual assignment completed during the course.

The included projects demonstrate the progression from introductory MATLAB programming and signal manipulation toward implementing complete digital signal processing pipelines capable of analyzing and enhancing real-world audio signals.

The semester project contains a more detailed README, technical report, source code, representative datasets, and sample results illustrating the complete processing workflow.
