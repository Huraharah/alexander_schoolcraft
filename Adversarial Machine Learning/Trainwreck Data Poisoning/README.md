# Trainwreck: Adversarial Attack on Image Classifiers

A reproduction and analysis of the paper:

> *Trainwreck: A Damaging Adversarial Attack on Image Classifiers*

Completed for **CSCI 4880 – Applications of Machine Learning to Computer Security**.

---

## Project Overview

The objective of this project was to study and reproduce the Trainwreck adversarial attack against image classification systems.

The project investigates how carefully crafted adversarial perturbations can significantly degrade image-classification performance while remaining difficult to detect.

Note on the presentation: The PowerPoint presentation contains several hidden slides that were used as presenter cues during the original classroom presentation. These slides include speaker notes for live demonstrations of specific portions of the accompanying Jupyter notebook and do not contain additional project material.
