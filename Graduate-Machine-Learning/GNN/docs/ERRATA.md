# Report Erratum

The included report was part of the original group submission. Its final results
section mistakenly incorporates metrics from an earlier local experiment that
used adaptive graph construction.

The final course implementation used a fixed 7 Å neighborhood cutoff as required
by the instructor. The authoritative results for that implementation are those
shown in the accompanying presentation and the repository's `outputs/`
directory.

The earlier adaptive graph design produced substantially stronger results but was
not the final submitted configuration.
