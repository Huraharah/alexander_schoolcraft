# Bank Global IT Asset Management Database

## Overview
--------
Designed and implemented a relational database for a fictional banking
organization to manage hardware assets, software installations,
branch locations, and server connectivity.

## Technologies
------------
• MySQL
• SQL
• ERDPlus
• Relational Database Design

## Features
--------
• Conceptual ER modeling
• Relational schema design
• Normalized database structure
• Foreign key constraints
• Many-to-many bridge tables
• Stored procedures
• Aggregate reporting
• Multi-table joins
