# CSCI 4800 – Machine Learning

This directory contains selected coursework completed for **CSCI 4800 – Machine Learning**. The projects introduce the complete machine learning workflow, beginning with data preparation and exploratory analysis before progressing through supervised learning techniques and foundational neural learning algorithms.

The coursework emphasizes both practical machine learning using established Python libraries and first-principles implementations of classical learning algorithms, providing a foundation for more advanced machine learning research.

These projects established the foundation for my later graduate research into neural networks, GPU computing, and transformer architectures.

---

## Projects

### Foundations

#### Data Manipulation with Pandas

Introduces exploratory data analysis, data cleaning, visualization, and statistical summaries using Pandas and related scientific Python libraries.

**Concepts**

- Data preprocessing
- Exploratory Data Analysis (EDA)
- Pandas
- Data visualization
- Statistical summaries

---

#### Classification with scikit-learn

Applies supervised classification techniques to real-world datasets using several classical machine learning algorithms.

**Concepts**

- Classification
- Logistic Regression
- k-Nearest Neighbors
- Support Vector Machines
- Decision Trees
- Model evaluation

---

#### Regression with scikit-learn

Explores regression techniques and performance evaluation using continuous prediction problems.

**Concepts**

- Linear Regression
- Regression metrics
- Feature analysis
- Model evaluation
- Prediction

---

### Foundational Neural Networks

#### Perceptron

A first-principles object-oriented implementation of the Perceptron learning algorithm.

**Concepts**

- Linear classifiers
- Binary classification
- Weight updates
- Decision boundaries

---

#### Adaline

An object-oriented implementation of the Adaptive Linear Neuron (Adaline) learning algorithm.

**Concepts**

- Gradient descent
- Mean Squared Error (MSE)
- Linear activation
- Adaptive learning

## Repository Organization

The projects are organized into two categories:

- **Foundations**, which focus on practical machine learning workflows using established Python libraries.
- **Neural Learning Algorithms**, which implement foundational learning algorithms from first principles.

Together these projects illustrate the progression from exploratory data analysis and classical machine learning toward implementing learning algorithms directly—a progression that ultimately informed later research projects such as **Transformer_Toy**.
