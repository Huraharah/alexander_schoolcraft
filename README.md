# Computer Science Coursework Portfolio

A curated collection of selected undergraduate and graduate coursework in computer science, software engineering, machine learning, databases, algorithms, and cybersecurity.

This repository preserves projects that demonstrate meaningful technical concepts, application development, or progression in my academic work. It is intentionally selective rather than a complete archive of every assignment.

## Repository Overview

### [Java Snake Game](Java-Snake-Game/)

A custom-rendered Snake-inspired desktop game developed during my second programming course using Java Swing, AWT, and Java2D.

**Highlights**
- Interactive desktop GUI
- Keyboard and mouse input
- Collision detection
- Dynamic scoring and difficulty
- Custom polygon-based graphics
- Start, game-over, and replay states

**Technologies:** `Java` `Swing` `AWT` `Java2D`

### [Universal Gift Registry](Registry-Project/)

A database-backed registry system developed across two separate course projects: a JavaFX desktop application and a later web-based implementation.

The project represents my first substantial application-development work involving user interfaces, backend logic, persistent storage, validation, application architecture, testing, and project documentation.

#### Desktop Application

A JavaFX desktop application using Maven, FXML, JDBC, and an Azure SQL backend.

**Highlights**
- User registration and authentication
- Password recovery using security questions
- Registry creation and management
- Product capture through an embedded browser
- Search for other users’ registries
- Purchase-state tracking
- Shipping-address visibility controls
- Structured input validation and error handling

**Technologies:** `Java` `JavaFX` `FXML` `Maven` `JDBC` `Azure SQL` `MVC`

[View the Java desktop implementation](Registry-Project/Java-Implementation/)

#### Web Application

A browser-based reimplementation of the registry system developed for CSCI 3000 – Web Development.

**Highlights**
- HTML, CSS, and JavaScript frontend
- Node.js and Express backend
- SQL database connectivity
- Form validation and sanitization
- Registry management and user-search workflows
- Local client/server deployment

**Technologies:** `HTML` `CSS` `JavaScript` `Node.js` `Express` `SQL`

[View the web application repository](https://github.com/Huraharah/Web_Development)
