## Note on Coursework

These projects were completed at different stages of my academic development. They are preserved with only minimal modifications where necessary (such as improving portability, removing machine-specific paths, or excluding security-sensitive artifacts) in order to accurately reflect the original work while remaining suitable for public release.

Some projects were completed individually, while others were developed as team projects. Team-based project READMEs identify the collaborative context and my specific role or contributions where appropriate.
